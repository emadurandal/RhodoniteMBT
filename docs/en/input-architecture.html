Input Architecture

Input is split into platform-independent emadurandal/rhodonite_core/input state and thin browser / SDL3 adapters. Gameplay code should not depend on DOM or SDL3 event types.

Event Flow

flowchart LR DOM[Browser DOM events] --> BA[Browser adapter] SDL[SDL3 poll events] --> SA[SDL3 adapter] BA --> Q[InputState event queue] SA --> Q Q --> BF[input.begin_frame] BF --> P["rhodonite/input phase"] P --> U["update / fixed_update / render_extract"]

Engine::run_frame calls input.begin_frame() at frame start. Multi-surface engines keep one InputState per surface.

Core Model

TypeRole
KeyCodeOpen string identifier using browser-style physical key names.
MouseButtonLeft, Middle, Right, Back, Forward, or Other(Int).
Modifiersshift / ctrl / alt / meta snapshot.
InputEventNormalized events enqueued by platform adapters.
InputStateTracks down/pressed/released, pointer delta, wheel delta, and frame events.

Adapters And Rules

  • Browser MoonBit adapter: emadurandal/rhodonite/app/browser.
  • Browser TypeScript adapter: rhodonite-mbt/app through installBrowserInputCallbacks / installBrowserInput.
  • SDL3 adapter: emadurandal/rhodonite_app_sdl3/sdl3.
  • Browser uses KeyboardEvent.code; SDL3 maps scancodes to the same browser-style names when possible.
  • Pointer coordinates are surface-local. Browser converts CSS pixels to backing size; native uses window-relative coordinates.
  • Pointer and wheel deltas reset every frame and accumulate events applied during that frame.

Camera Controllers

MoonBit samples use the builtin OrbitCameraController, CameraHomeTransform, and CameraLens components. Scenes implicitly declare standard camera runtime integration once a main camera is assigned; samples call Scene::use_common_runtime only when boolean flags need to choose different standard systems. TypeScript samples use the matching Scene.useCommonRuntime. Engine::initialize() installs the builtin orbit-camera input handler through keyed phase handler registration, so repeated common runtime reflection does not register the same handler again. TypeScript samples use matching byte layouts in moon/rhodonite_core/src/ecs/ts/camera-control.ts and input folding in moon/rhodonite/src/app/ts/orbit-camera-input.ts.
