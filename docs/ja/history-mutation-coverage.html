履歴 Mutation Coverage

このページは ECS mutation API と Undo/Redo behavior の監査表です。mutating API を追加する場合は、このページと対応する coverage test を同時に更新します。

TypeScript wrapper も MoonBit surface と同じ分類に従います。公開 wrapper method はここに載っている tracked API へ委譲するか、raw guarded のままにするか、intentionally untracked として docs に明記し、wrapper 側で挙動を足す場合は対応する TypeScript coverage も追加します。

TypeScript public wrapper surface は history-mutation-coverage.test.ts でも監査します。World、WorldHistory、query row、raw query archetype、SystemRunner、CommandBuffer に method を追加する場合は、その audit で tracked、tracked callback、tracked command phase、raw guarded、intentionally untracked、read-only、history-control のいずれかに分類します。

同じ test は pkg.generated.mbti から MoonBit public surface も監査します。public ECS method を追加または削除し、moon info で interface を更新した後は、その test の MoonBit ledger も更新し、method に明示的な history classification を付けます。

Tracked API parity も MoonBit public surface、js_bridge、ecs-bridge*.d.ts、TypeScript wrapper をまたいで監査します。tracked Undo/Redo API を追加する場合は、bridge declaration、wrapper import、public wrapper method または mirror export、parity ledger を同じ変更で更新します。MoonBit-only typed helper は TypeScript bridge を持つまで MoonBit-only として明示的に列挙します。

Coverage Classes

ClassBehaviorExpected tests
TrackedWorldHistory 経由で可逆 delta を記録します。Undo / Redo で before / after state が復元されること。
Tracked callbackcallback 内だけ mutable bytes を貸し出し、callback 境界で変更を記録します。guarded transaction で tracked callback は成功し、raw callback は abort すること。
Tracked command phasesystem が command を queue し、WorldHistory::run_system_phase が tracked API 経由で適用します。queued command が phase label の 1 件の undoable record になること。
Raw guarded意図的に history を通しませんが、guarded transaction 中は abort します。guarded transaction で panic / throw する coverage test を持つこと。
Intentionally untrackedderived runtime data、registration metadata、readback plumbing を更新します。history 対象外である理由を docs に書くこと。
History-controlcomponent data を直接変更せず、history state や tracked operation の scope を制御します。commit、cancel、disabled、nested case の control-flow test を持つこと。

Raw And Untracked Surface

SurfaceRecord statusGuarded transaction status
Direct World mutator と raw World::spawn_batchraw で record は作りません。runtime system と simulation は editor history の外で使えます。abort します。guarded editor transaction 内では対応する WorldHistory helper を使います。
Component registration と identity metadata意図的に untracked な setup metadata です。component schema は operation 単位の editor history ではありません。registration は guarded 中に abort します。metadata read は許可されます。
GlobalTransform / Camera blob upload、resize、dense write helper意図的に untracked な derived data です。authoring change には専用の WorldHistory helper を使います。mutating helper は guarded 中に abort します。
GlobalTransform / Camera blob drain と readback helperreadback plumbing で record は作りません。ECS authoring state を変更しないため許可されます。
Transform propagation と camera view update system意図的に untracked な derived recomputation です。guarded editor transaction の外の runtime path で使います。
Read-only query と component metadata readhistory behavior は不要です。許可されます。
