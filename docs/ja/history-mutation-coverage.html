履歴 Mutation Coverage

このページは ECS mutation API と Undo/Redo behavior の監査表です。mutating API を追加する場合は、このページと対応する coverage test を同時に更新します。

Coverage Classes

ClassBehaviorExpected tests
TrackedWorldHistory 経由で可逆 delta を記録します。Undo / Redo で before / after state が復元されること。
Tracked callbackcallback 内だけ mutable bytes を貸し出し、callback 境界で変更を記録します。guarded transaction で tracked callback は成功し、raw callback は abort すること。
Tracked command phasesystem が command を queue し、WorldHistory::run_system_phase が tracked API 経由で適用します。queued command が phase label の 1 件の undoable record になること。
Raw guarded意図的に history を通しませんが、guarded transaction 中は abort します。guarded transaction で panic / throw する coverage test を持つこと。
Intentionally untrackedderived runtime data、registration metadata、readback plumbing を更新します。history 対象外である理由を docs に書くこと。

SurfaceCoverage expectation
WorldHistory::create_entity、create_entities、destroy_entitydestroy restore を含め、EntityId と generation が Undo / Redo をまたいで維持されます。
add_component、add_component_bytes、set_component_bytes、remove_componentcomponent presence と payload bytes が round-trip します。
add_component_bytes_many、set_component_bytes_manybulk helper は先に検証し、1 operation として記録し、対象 row 全体を復元します。

Tracked camera-control helperorbit setup、lens、controller、home、transform sync、blob sync helper は editor step を undoable record にまとめます。

Query And Command Surface

SurfaceUndo/Redo status
QueryRow::write_tracked、RawQueryRow::write_trackedrow authoring 用の tracked callback API です。recording disabled 時は history copy なしで委譲します。
RawQueryArchetype::write_column_trackedcontiguous column edit 用の tracked callback API です。column を snapshot し、変更された row だけを記録します。
CommandBuffer through WorldHistory::run_system_phaseeditor system 用の tracked command path です。対応 command は該当する history method に dispatch されます。
Raw QueryRow::write、RawQueryRow::write_view、RawQueryArchetype::write_columnRaw guarded です。untracked であり、guarded history transaction 中は abort します。
Raw SystemRunner::run_phaseRaw guarded です。history が必要な command-buffer edit では WorldHistory::run_system_phase を使います。

Raw And Untracked Surface

SurfaceStatus
Direct World mutator と raw World::spawn_batchRaw guarded です。runtime system と simulation は guarded editor transaction の外で使えます。
Component registration と identity metadata意図的に untracked です。component schema は application setup の一部であり、operation 単位の editor history ではありません。
GlobalTransform / Camera blob upload、drain、resize、dense write、readback helper意図的に untracked な derived data です。authoring change には専用の WorldHistory helper を使います。
Transform propagation と camera view update system意図的に untracked な derived recomputation です。
Read-only query と component metadata readhistory behavior は不要です。
