モジュール境界

RhodoniteMBT は root moon.work で結合された MoonBit workspace です。各 module は公開責務を分け、examples は release 対象から外します。

このページの読み方

まず「どの directory が何を担当するか」を掴むためのページです。RhodoniteMBT を使うだけなら facade の emadurandal/rhodonite と samples を中心に見れば十分です。低レベル module は、CPU-only logic、WebGPU wrapper、native SDL3 runtime を分けて保守するためにあります。

Workspace Modules

ModuleDirectoryRole
emadurandal/sdl3moon/sdl3SDL3 MoonBit binding fork。native runtime が使う C stub と include flags を持つ。
emadurandal/rhodonite_coremoon/rhodonite_coremath、binary writes、JS bridge、CPU-only ECS、platform-independent input、ECS benchmark。
emadurandal/rhodonite_webgpumoon/rhodonite_webgpuWebGPU abstraction。browser と native の object backend を virtual package で切り替える。
emadurandal/rhodonitemoon/rhodonitePublic facade。Engine / Scene / Renderer / browser platform helpers と TypeScript app wrapper を公開する。
emadurandal/rhodonite_app_sdl3moon/rhodonite_app_sdl3SDL3 native app runtime helpers。window/event loop、resize、surface suspension、Metal/Vulkan WebGPU bootstrap。
emadurandal/rhodonite_examplesmoon/rhodonite_examplesRunnable samples、visual regression harness、sample-only shared helpers。

Dependency Direction

flowchart LR sdl3["sdl3"] core["rhodonite_core"] webgpu["rhodonite_webgpu"] facade["rhodonite facade"] app_sdl3["rhodonite_app_sdl3"] examples["rhodonite_examples"] webgpu --> core facade --> core facade --> webgpu app_sdl3 --> facade app_sdl3 --> core app_sdl3 --> webgpu app_sdl3 --> sdl3 examples --> facade examples --> app_sdl3 examples --> core examples --> webgpu
  • rhodonite_core は GPU device、DOM、SDL3 を知らない。
  • rhodonite_webgpu/webgpu_objects は virtual package。workspace-wide check 用の default stub があり、runnable package は js または native backend を override する。
  • runtime は facade の emadurandal/rhodonite/app に置く。browser platform は emadurandal/rhodonite/app/browser、SDL3 platform は emadurandal/rhodonite_app_sdl3/sdl3 に置く。
  • rhodonite_examples は high-level facade と low-level modules の両方を import できるが、library module は examples に依存しない。

Release Units

Maintainer / Agent Notes

ここから先は release、npm package、検証コマンドのための保守者向け情報です。module dependency や package entrypoint を変える場合は、この表、README、関連 scripts を同じ変更で同期します。

Mooncakes publish は dependency order で行います。root script は workspace の path deps を一時的に registry version へ書き換え、publish 後に戻します。

  1. emadurandal/sdl3
  2. emadurandal/rhodonite_core
  3. emadurandal/rhodonite_webgpu
  4. emadurandal/rhodonite
  5. emadurandal/rhodonite_app_sdl3
pnpm run publish:moon
PUBLISH_MOON_DOWNSTREAM_ONLY=1 pnpm run publish:moon
PUBLISH_MOON_APP_SDL3_ONLY=1 pnpm run publish:moon

emadurandal/rhodonite_examples は repo-only で、publish script は公開しません。

npm Package

packages/rhodonite-mbt は ESM-only の npm package です。exports は root、./math、./ecs、./app です。TypeScript wrapper と MoonBit JS bridge を bundle し、examples や SDL3 native runtime は含めません。

pnpm run build:npm
pnpm run pack:npm
pnpm run publish:npm
