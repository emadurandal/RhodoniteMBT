用語集

RhodoniteMBT の docs とコードでよく出る名前を、最初に読む人向けに短くまとめます。詳細な設計や制約は各参照ページに分けています。

用語意味主な参照先
Engineframe の進行、scene、surface、input、renderer、phase handler をまとめて所有する runtime object。Engine / Scene
Scene表示や更新の単位。1つの World、system runner、main camera、enabled/visible state を持つ。Engine / Scene
WorldECS storage。entity、component、archetype、builtin blob store を持つが、GPU resource や platform loop は持たない。ECS
ECSEntity Component System。object を entity ID と component data の組み合わせとして扱い、system が query して更新する方式。ECS
Entityscene 内の1つの対象を指す ID。component を付けることで transform、renderable、camera などの性質を持つ。ECS
Componententity に付く data の種類。例として Transform3D、GlobalTransform、Camera、Renderable がある。ECS
System特定の phase で ECS data を読む・書く処理。query と command buffer を使って world を更新する。ECS
Rendererscene から renderable entity を取り出し、登録済み mesh/material と GPU resource を使って描画する object。描画
Renderable描画対象であることを示す component。mesh handle、material handle、visibility などを renderer に渡す。描画
Surfacecanvas や native window のような描画先。surface ごとに input と render target resources を持つ。Engine / Scene
Phase1 frame 内の処理順序を表す名前。input、update、render extract、render、present などがある。Engine / Scene
BlobGPU upload 向けの packed bytes。GlobalTransform や Camera の大きな行 data を component row から分けて保持する。ECS
WorldHistoryWorld の変更を undo/redo できるよう記録する optional layer。Undo / Redo
tracked / rawtracked API は履歴に記録され、raw API は直接 world を変更する。editor 操作では tracked、runtime hot path では raw を使うことが多い。履歴 Mutation Coverage
