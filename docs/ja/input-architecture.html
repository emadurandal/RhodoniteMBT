入力アーキテクチャ

入力は platform-independent な emadurandal/rhodonite_core/input と、browser / SDL3 adapters に分けます。gameplay code は DOM や SDL3 型を直接見ません。

入力の基本

browser と native では event の形が違いますが、RhodoniteMBT はどちらも InputState に正規化します。gameplay や camera controller は DOM/SDL3 を直接読まず、frame ごとの key、mouse、pointer、wheel state を読みます。

Event Flow

flowchart LR DOM[Browser DOM events] --> BA[Browser adapter] SDL[SDL3 poll events] --> SA[SDL3 adapter] BA --> Q[InputState event queue] SA --> Q Q --> BF[input.begin_frame] BF --> P["rhodonite/input phase"] P --> U["update / fixed_update / render_extract"]

Engine::run_frame は frame 冒頭で input.begin_frame() を呼び、前フレームから enqueue された event を現在フレームの state に確定します。multi-surface では surface ごとに InputState を持ちます。

入力を読む gameplay system は通常 rhodonite/update に置きます。controller component を同一フレームで後続 update/render に反映したい場合は rhodonite/input に置けます。

Adapters

Maintainer / Agent Notes

adapter を変更する場合は、browser と SDL3 が同じ KeyCode / pointer coordinate model に揃っているか確認します。multi-surface sample では surface-local input の分離も regression 対象です。

  • Browser MoonBit adapter は emadurandal/rhodonite/app/browser にあります。install_browser_input、install_browser_surface_input、platform runner が DOM events を InputState へ enqueue します。
  • Browser TypeScript adapter は rhodonite-mbt/app の installBrowserInputCallbacks / installBrowserInput を使います。
  • SDL3 adapter は emadurandal/rhodonite_app_sdl3/sdl3 にあります。SDL events と render 直前の mouse snapshot を組み合わせて state を補完します。

Key And Mouse Rules

  • KeyCode は enum ではなく open identifier です。unknown key を保持でき、adapter の mapping を段階的に改善できます。
  • browser は KeyboardEvent.code を使い、SDL3 は scancode を KeyW、ArrowLeft、Space などの browser-style name へ正規化します。
  • pointer coordinates は canvas/window surface 座標です。browser は CSS pixel から backing size へ変換します。
  • pointer_delta_x/y と wheel_delta_x/y は frame ごとに 0 に戻り、その frame の event 合計になります。
  • SDL3 wheel は DOM wheel に近い符号と大きさへ寄せ、上方向 scroll が dolly-in になるよう正規化します。

Surface-local Input

multi-surface では Platform が device/event loop を共有し、Surface が canvas/window/swapchain/input を所有します。render path の camera/controller は Engine::surface_input(surface_id) または FrameState::input() を読みます。

Camera Controllers

MoonBit samples は builtin の OrbitCameraController、CameraHomeTransform、CameraLens component を使います。Scene は main camera が設定された時点で標準 camera runtime integration を暗黙宣言し、sample は標準 system の bool flag を変えたいときだけ Scene::use_common_runtime を呼びます。TypeScript samples は対応する Scene.useCommonRuntime を使います。Engine::initialize() が builtin orbit-camera input handler を keyed phase handler registration 経由で追加するため、common runtime reflection を繰り返しても同じ handler を再登録しません。TypeScript samples は moon/rhodonite_core/src/ecs/ts/camera-control.ts と moon/rhodonite/src/app/ts/orbit-camera-input.ts で同じ byte layout と phase order を使います。
