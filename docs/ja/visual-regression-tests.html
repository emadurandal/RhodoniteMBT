Visual Regression Tests

Visual regression は real sample path を WebGPU backend で render し、readback した RGBA8 pixels を PNG golden files と比較します。MoonBit browser、TypeScript browser、native sample は Platform single-frame path を通るため、Engine setup、common runtime handlers、surface configuration、presentation も対象になります。WASM host variants は browser canvas へ render し、presented canvas pixels を readback します。

Flow

flowchart LR M[visual_samples.tsv] --> H[Native or browser harness] H --> E[Sample setup_engine] E --> R[Platform single-frame or browser canvas render] R --> B[RGBA8 readback] B --> P[PNG compare or update] P --> G[__image_snapshots__]

Commands

pnpm run test:examples:visual
pnpm run test:examples:visual:native
pnpm run test:examples:visual:browser
pnpm run test:examples:visual:update
pnpm run test:examples:visual:update:native
pnpm run test:examples:visual:update:browser

pnpm run test:examples:visual -- --verbose

Manifest And Golden Files

test matrix は visual_samples.tsv にあります。各 row は target、id、display name、PNG filename、max_mismatch_rate、perceptual_threshold を持ちます。

golden PNG は moon/rhodonite_examples/src/visual_regression/__image_snapshots__ に置きます。browser harness は MoonBit JS、WASM、WASM-GC、TypeScript host variants を含みます。

Comparison

  • native helper は SDL3 Platform single-frame presentation を capture し、mizchi/image で PNG を decode して mizchi/pixelmatch で perceptual comparison を行います。
  • browser harness は browser 内で createImageBitmap により presented canvas pixels を読み、OffscreenCanvas で PNG decode/encode して Node runner へ result を POST します。
  • max_mismatch_rate=0.0005 は小さな backend / driver variance を許容しつつ、目に見える regression を検出する値です。
  • snapshot update は RHODONITE_UPDATE_VISUAL_SNAPSHOTS=1 で現在の readback output を golden PNG に書き戻します。rendered result を確認してから使います。

Implementation Notes

  • native visual package は supported_targets = "native"、browser visual package は supported_targets = "js"。
  • native は webgpu_objects/native を override し、次の canvas presentation を present 前に capture します。browser は webgpu_objects/js を override し、MoonBit、TypeScript、WASM variants の presented canvas pixels を readback します。
  • scripts/run-visual-regression.mjs は native/browser をまとめ、MoonBit warnings を通常非表示にします。
  • scripts/run-browser-visual-regression.mjs は Vite と local result server を起動し、headless Chrome/Chromium から result を受け取ります。
  • WebGPU adapter creation や Chrome startup に失敗する環境では skip message を出して pass します。golden 更新は WebGPU-capable machine で行います。
