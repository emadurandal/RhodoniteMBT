履歴シリアライズ

この文書は将来の WorldHistory export/import に向けた永続化境界を定義します。現行実装の undo/redo record は in-memory のみです。

Status

  • WorldHistory は現時点で serialized history API を公開していません。
  • undo_summary と redo_summary は retained in-memory record の diagnostic view です。serialized history archive や compatibility format ではありません。
  • 将来の永続化では format_version を持つ明示的な history format を使います。MoonBit の enum layout、object layout、内部 variant 名は stable file ABI として扱いません。
  • serialized form は editor/session persistence 向けです。任意の runtime simulation や GPU resource state の replay は対象にしません。

Record Shape

将来の history archive は undo stack と redo stack を ordered record として保存します。各 record は label、record-level metadata、ordered delta を持ちます。create 後に component を追加する transaction のように、delta の順序そのものが意味を持ちます。

FieldPolicy
format_version必須です。未対応の major version は推測せず reject します。
library_version診断 metadata です。互換性判断は format_version と schema key で行います。
recordscommitted undo/redo record を stack order で保存します。
label任意の UI metadata です。replay semantics には影響しません。
deltas明示的な variant tag と typed payload field を持つ ordered logical delta です。

Identity

Entity identity は runtime restoration policy と同じく index + generation として保存します。destroy の Undo は同じ EntityId を復元します。Component identity にはより強い規則が必要です。ComponentTypeId.index は session-local なので、永続化された key として単独では使いません。

IdentitySerialization policy
Entityindex と generation を保存します。import は target world がその id を reserve / restore できることを検証します。
Builtin componentTransform3D、ChildOf、GlobalTransform、Camera のような stable builtin name を保存します。
User CPU componentapplication-provided stable key と schema version または hash を必須にします。登録済み component と一致しない場合は replay を reject します。
Component indexlocal hint として cache してもよいですが、session をまたいだ authoritative key にはしません。

Payloads

User CPU component は byte-exact payload として扱います。before/after bytes は対応する component schema key と一緒に保存された場合だけ安全に replay できます。schema が変わった場合、bytes を再解釈せず delta を reject します。

Blob-backed builtin では CPU ref bytes を source of truth として永続化しません。GlobalTransform は logical matrix row と format metadata を保存します。Camera は logical camera GPU row payload と runtime helper に必要な camera metadata を保存します。import 時は現在の session の world が新しい blob row を割り当て、その payload を書き込み、有効な CPU ref component を作ります。

Replay Validation

import と replay は runtime undo/redo と同じ防御方針を使います。record 適用前に検証し、stale delta や schema mismatch を reject し、検証失敗時は stack を動かしません。byte budget と record count limit は runtime retention policy であり、archive compatibility policy ではありません。

Out Of Scope For V1

  • Renderer の mesh/material object、GPU buffer、device resource。
  • ECS component bytes から参照される asset lifetime と external resource handle。
  • collaborative editing merge、conflict resolution、operation transform。
  • 明示的な format_version compatibility policy を超えた cross-engine-version replay。
  • open transaction の serialization。永続化対象候補は committed undo/redo record のみです。
